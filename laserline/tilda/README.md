# Laserline → Тильда (светлая версия)

Готовый набор для переноса светлого макета на Тильду. Страница собрана как **набор HTML-блоков (T123)**: внешний вид, подбор комплекта, окно «Модель гофрозащиты», меню на телефоне и появление блоков при скролле работают без Zero Block.

Проверено локально в браузере (десктоп 1440 px и телефон 390 px, подбор → окно → форма, меню). **В самой Тильде не проверялось**: у меня нет доступа к вашему проекту.

## Как вставлять

Один T123 вмещает ограниченный объём текста. Весь `all-in-one.html` (около 150 КБ) в него не помещается, Тильда пишет «Слишком много текста». Поэтому вставляйте **по блокам**: каждый файл из `blocks/` занимает не больше 26 КБ.

Порядок на странице: `00-styles` → `01-header` → … → `11-footer` → `99-scripts`. Каждый файл идёт в отдельный блок **T123 «HTML»** (раздел «Другое»), отступы блока 0. Блок `00-styles` ничего не показывает, он подключает шрифты и оформление. Если на вашем тарифе доступен HEAD, вместо него можно вставить `head.html` в настройки сайта.

`all-in-one.html` оставлен для локального просмотра и не предназначен для вставки в Тильду.

## Тёмная версия

Та же страница в тёмной теме собирается командой `LL_THEME=dark python3 build.py`. Файлы лежат в `blocks-dark/` (13 блоков, нумерация та же), предпросмотр: `preview-dark.html`, стили для HEAD: `head-dark.html`. Вставлять так же, как светлую: каждый файл в свой блок T123, первым `00-styles`, последним `99-scripts`. Светлые и тёмные блоки в одной странице не смешивайте. Тёмная тема — это `src/ll-dark.css` поверх `src/ll.css` плюс перекраска иллюстраций в `build.py` (`to_dark`).

## Станки в каталоге

В карточке каталога слева рисуется станок выбранной модели (15 моделей, схематично). При наведении курсора портал едет, голова ходит и вычерчивается контур реза; на телефоне анимация идёт сама. Рисунки строятся скриптом из `99-scripts.html` (исходник `src/machines.js`), картинок загружать не нужно. Чтобы изменить вид станка или добавить модель, правьте таблицу `MM` и `src/machines.js`, затем `python3 build.py`. Для замены на реальные фото достаточно подставить `<img>` в `#llMachine`.

## Что внутри

| Файл | Куда вставлять |
|---|---|
| `blocks/00-styles.html` | Первый блок T123 на странице: шрифты и все стили. Для тарифов без HEAD |
| `head.html` | То же самое, но для Настройки сайта → Ещё → **HTML-код для вставки внутрь HEAD** (платный тариф), тогда блок 00 не нужен |
| `blocks/01-header.html` … `blocks/11-footer.html` | Каждый — отдельный блок **T123 «HTML»** (раздел «Другое»), в порядке номеров |
| `blocks/99-scripts.html` | Последний блок T123 на странице (скрипты: меню, подбор, окно, форма, появление блоков) |
| `preview.html` | Локальный предпросмотр всей страницы (открывается двойным кликом) |
| `assets/` | Логотипы Laserline (SVG) на случай, если понадобятся отдельно |
| `src/ll.css`, `build.py` | Исходники. После правок: `python3 build.py`, файлы пересоберутся |

Кастомный код в HEAD доступен на платных тарифах Тильды.

## Порядок работы

1. Создайте пустую страницу, в её настройках отключите стандартные шапку и подвал Тильды.
2. **Шрифты.** Настройки сайта → Шрифты → загрузите Magistral CTT Bold (если есть лицензия на веб-использование), семейство назовите `Magistral CTT`. Без него заголовки покажутся шрифтом Exo 2. IBM Plex подключается из Google Fonts в `head.html`.
3. Добавьте первым блоком T123 файл `00-styles.html` (или вставьте `head.html` в HEAD, если доступно).
4. Добавьте блоки T123 по порядку и вставьте в каждый содержимое файла. В настройках блока отступы поставьте 0.
5. Последним блоком добавьте `99-scripts.html`.
6. Меню и кнопки ведут на якоря: `#catalog`, `#series`, `#diagnostics`, `#video`, `#guarantees`, `#delivery`, `#request`, `#contacts`. Якоря заданы внутри блоков, отдельные блоки-якоря не нужны.

## Что заменить своими данными

- **Ссылки на соцсети:** в `build.py` строка `TG_URL, MAX_URL, VK_URL`, затем пересобрать.
- **Телефон и e-mail** в футере (`blocks/11-footer.html`).
- **Логотипы заказчиков и отзывы** (`blocks/08-clients.html`): сейчас заглушки. Реальные логотипы и тексты — только с письменного согласия заказчиков.
- **Видео краш-теста:** в блоке `06-video.html` у `<div class="ll-player" id="llPlayer">` добавьте `data-src="адрес iframe Rutube/YouTube/VK"`.
- Пустые значения «до __ мм» у Econom и Optimal.
- Адрес политики конфиденциальности (ссылка `#` в форме).

## Форма заявки

Форма в блоке `10-request.html` нужна как оформление. **В Тильду заявки она не попадает.** Есть два варианта:

1. Рекомендуется: поставьте штатный блок формы Тильды на место этого блока, поля те же (вид заявки, имя, компания, марка и модель станка, e-mail, телефон/мессенджер, согласие), цвета берите из макета: фон `#072730`, кнопка `#E8FC5C` с текстом `#072730`. Подключите приём заявок на почту, в Telegram или в CRM.
2. Либо задайте адрес приёма, например в блоке скриптов: `window.LL_FORM_ENDPOINT = "https://…"`. Тогда форма отправит JSON методом POST.

## Что проверить после вставки

- Заголовки в Magistral CTT не переносятся лишней строкой (он шире Exo 2).
- Меню на телефоне открывается, ссылки прокручивают к секциям.
- Подбор комплекта открывает окно, «Подобрать эту модель» ведёт к форме и подставляет станок.
- Скорость: страница тяжёлая из-за встроенных SVG (шапка и футер около 22 КБ каждая). Если нужно, замените логотип картинкой из `assets/`.
- Появление блоков при скролле отключается у посетителей с настройкой «уменьшить анимацию».

## Что сознательно не перенесено

- Закреплённая шапка при прокрутке (в T123 она ломается): если нужна, используйте закрепление блока в настройках Тильды.
- Тёмная версия и мобильный макет Figma перенесены только как адаптивная вёрстка этого набора, отдельных тёмных стилей нет.
