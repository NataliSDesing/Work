# Хронографы — прототип игры по всеобщей истории (7 класс)

Эксперимент для небольшого класса. Без сервера и регистрации.

- `index.html` — игра для учеников (открывается с телефона).
- `teacher.html` — сводка для учителя: ученики присылают «код отчёта», учитель вставляет коды.
- `data.js` — миссии, вопросы, карточки. Здесь правится всё содержание.

Прогресс хранится в браузере телефона ученика. Вопросы нужно сверить с учебником.

Локальный запуск: `npx serve .` или просто открыть `index.html`.

## Вход по кодам

- `teacher.html`: учитель вносит список класса, получает код и личную ссылку для каждого ученика, может скопировать всё для рассылки или напечатать карточки.
- `auth.js`: код шифрует имя ученика, поэтому игре не нужен список класса и вход работает на любом телефоне.
- Прогресс каждого ученика хранится в браузере его устройства под своим кодом. На общем телефоне можно сменить ученика в профиле. Перенос на другой телефон: «Сохранение прогресса» в профиле.
- Это не защита от взлома: код можно подобрать, зная алгоритм. Для эксперимента в классе этого достаточно.
