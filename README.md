# Хронографы — прототип игры по всеобщей истории (7 класс)

Эксперимент для небольшого класса. Без сервера и регистрации.

- `index.html` — игра для учеников (открывается с телефона).
- `teacher.html` — сводка для учителя: ученики присылают «код отчёта», учитель вставляет коды.
- `data.js` — миссии, вопросы, карточки. Здесь правится всё содержание.

Прогресс хранится в браузере телефона ученика. Вопросы нужно сверить с учебником.

Локальный запуск: `npx serve .` или просто открыть `index.html`.
